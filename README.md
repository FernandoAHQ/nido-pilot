# Nido

Una aventura web en español para que niñas y niños de 4 a 6 años practiquen patrones visuales AB, AAB, ABB y ABC.

## Desarrollo

```bash
npm install
npm run dev
```

## Verificación

```bash
npm test
npm run build
npx playwright install
npm run test:e2e
```

El progreso se guarda únicamente en `localStorage`. No se recopilan datos ni se utiliza un backend.
